3. We have following DF,

+---+---------+-------+
| id|    names|revenue|
+---+---------+-------+
|  1|{a, b, c}|     45|
|  2|{x, y, z}|     65|
|  3|{p, q, r}|     54|
+---+---------+-------+

Df's Schema is : 
root
 |-- id: integer (nullable = false)
 |-- names: struct (nullable = false)
 |    |-- c1: string (nullable = false)
 |    |-- c2: string (nullable = false)
 |    |-- c3: string (nullable = false)
 |-- revenue: integer (nullable = false)


Select id,c2 and revenue column from DF.



4. We have following DF,

+---+---------+-------+
| id|    names|revenue|
+---+---------+-------+
|  1|[a, b, c]|     45|
|  2|[x, y, z]|     65|
|  3|[p, q, r]|     54|
+---+---------+-------+

Df's Schema is,
root
 |-- id: string (nullable = false)
 |-- names: array (nullable = false)
 |    |-- element: string (containsNull = true)
 |-- revenue: integer (nullable = false)


Select id, 'element at first index of names array' and revenue column from DF.
